自僱人士和零工工作者如何為三藩市托兒補助證明收入？

1099、自由工作、現金收入和零工平台工作者申請全民早教 (ELFA) 時可用的收入證明文件。

首頁 › 三藩市托兒服務 › 財務援助 › 自僱收入證明

自僱人士、自由工作者和零工工作者可用以下文件為全民早教 (ELFA) 證明收入：(a) 自僱收入記錄（如 IRS 1040 表加 Schedule C 或 1099 對帳單）；(b) 適用時的工資單（週薪需4張連續工資單；雙週薪需2張）；或 (c) 無法提供正式文件時（例如現金收入），使用官方 ELFA 自我申報表。收入文件須在認證預約日期的30天內開出，W-2 或報稅表僅於1月至4月間接受（適用上一稅務年度）。入學後若收入有任何變動，須立即通知您的托兒機構。資料來源：ELFA 家庭入學申請表（中文）2025-26年度（English）。

可接受的收入證明文件 — 完整清單

請依據您的工作情況選擇適用文件。多數自僱申請人會提交兩類文件（例如上一年 Schedule C 加最近銀行對帳單），讓 R&R 機構看到年度基線和目前逐月收入。

  • IRS 1040 表及 Schedule C，來自最近一次報稅。 Schedule C 顯示您的自僱損益。請提交所有頁面。
  • IRS 1099-NEC 或 1099-K 表，來自最近一個稅務年度。 每個工作平台一份（Uber、DoorDash、Lyft、Instacart、TaskRabbit、Care.com 等）。
  • 最近三個月的收入明細，從零工應用程式後台下載。 Uber Driver 週收入、DoorDash Dasher 明細、Lyft 司機摘要 — PDF 或截圖均可。
  • ELFA 自我申報表（English），正式官方表格，須依偽證罪罰則簽署。 無法提供正式文件時使用，例如現金收入、新開業尚無報稅紀錄。
  • 最近三個月的銀行對帳單，顯示業務存款。 請標明業務相關的存款，工作人員便能區分個人轉帳。
  • 營業執照或虛擬商號登記 (DBA)，若您經營已登記的小型企業。
  • 最近90天內收到款項的客戶發票，適用於顧問、家教、創意或技術工作。
  • 本年度至今的損益表 (Profit & Loss)，由您簽名並註明日期。 一份簡單的月度收入減業務支出的 Excel 表即可接受。

常見情況

零工平台工作者 (Uber、DoorDash、Lyft、Instacart)

提交最近三個月的應用內收入摘要，加上上一年的 1099-NEC 或 1099-K。若您為多個平台開車，請附上每個平台的對帳單。請申報扣除油費、通行費和里程後的淨收入。

現金收入工作者（家庭托兒、清潔、建築、食物攤販）

因為沒有 W-2 或 1099，ELFA 接受官方的 ELFA 自我申報表。請附上銀行存款紀錄（若您存入現金），或常客確認每月付款金額的信件。

小型企業主和自由工作者

以最近一份 1040 表及 Schedule C 作為主要文件。若今年收入高於或低於去年，請附上本年度至今的損益表和三個月的業務銀行對帳單。

季節性或不穩定工作者（稅務準備員、活動工作人員、導遊、婚禮業者）

請申報預期年收入，而非僅僅是旺季收入。附上去年 Schedule C 和一份簡短說明，解釋您的收入模式。入學後若收入有任何變動，請立即通知您的托兒機構。
